## 2. Đặt model vào đúng chỗ
Mỗi `model.zip` vào `runs\EXP-02\<run-id>\model.zip`, với `<run-id>` trùng tên thư mục trong `results\raw\EXP-02`.
```powershell
foreach ($d in Get-ChildItem results\raw\EXP-02 -Directory -Filter "*_ppo_mask_*") {
  New-Item -ItemType Directory -Force "runs\EXP-02\$($d.Name)" | Out-Null
  "runs\EXP-02\$($d.Name)\model.zip  ->  " + (Test-Path "runs\EXP-02\$($d.Name)\model.zip")
}
```
Chép file DAT gửi vào các thư mục vừa tạo rồi chạy lại khối trên; cả 4 dòng phải là `True`.

## 3. Kiểm SHA256 và ghi manifest
```powershell
.\.venv\Scripts\python.exe scripts\manifest_row.py results\raw\EXP-02\*_ppo_mask_* --verify --append
```
Lỗi SHA256 lệch nghĩa là file chép sai: dừng lại và báo DAT, không ghi manifest.

## 4. Vẽ 3 quỹ đạo mỗi model (id, ood_cluster, ood_density; seed 100000)
```powershell
New-Item -ItemType Directory -Force figures | Out-Null
foreach ($d in Get-ChildItem results\raw\EXP-02 -Directory -Filter "*_ppo_mask_*") {
  $label = if ($d.Name -like "dr_*") { "dr_ppo" } else { "fixed_ppo" }
  $seed  = [regex]::Match($d.Name, "_s(\d+)_").Groups[1].Value
  foreach ($suite in "id", "ood_cluster", "ood_density") {
    .\.venv\Scripts\python.exe scripts\plot_trajectory.py --model "runs\EXP-02\$($d.Name)\model.zip" `
      --label "$label`_s$seed" --suite $suite --seed 100000 `
      --out "figures\EXP-02_traj_$label`_s$seed`_$suite.png"
  }
}
```
Mỗi lệnh in chỉ số episode và cờ suy biến. Chụp màn hình hoặc chép phần in ra gửi Claude; mở 12 hình trong `figures\`.
